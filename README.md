# DICOM Viewer Local

Visor DICOM basado en Cornerstone3D. Procesa los estudios localmente en el navegador.

## Desarrollo
npm install
npm run dev

## Producción
npm run build

El proyecto está preparado para GitHub Pages mediante GitHub Actions.

## Privacidad
Esta versión no incorpora servidor ni subida de estudios.

## Aviso
Visor técnico/educativo. No sustituye la interpretación de un profesional de la salud.
